# イベントスライド作成

スライドを作成または更新する前に、[スライド作成ルール](references/slide-rules.md)を全文読む。
完了を報告する前に、[スライド完了チェックリスト](references/slide-checklist.md)をすべて確認する。

## デフォルトスライド

次の一覧からイベントに必要なページだけを選ぶ。

- 開始前案内：開始時刻とイベントのハッシュタグを案内する
- 臨時案内：機材トラブル、入館混雑、ネットワーク障害などを案内する
- イベントの表紙：イベント名、テーマ、開催日、開催時間、会場を掲載する
- アジェンダ：各セッションの時間、タイトル、登壇者を一覧で掲載する
- AI駆動開発勉強会の紹介：勉強会の概要、公式サイト、イベントページを紹介する
- 支部・コミュニティの紹介：地方支部、テーマ支部、全国マップを紹介する
- 主催・共催団体の紹介：イベントを運営する団体の目的や活動を紹介する
- セッションの紹介：登壇者名、所属、セッションタイトルを掲載する
- お知らせのタイトルスライド：スポンサーや関連イベントの紹介が始まることを示す
- スポンサーの紹介：主催者が、会場、配信、懇親会などの区分ごとにスポンサー名やロゴを紹介する
- 関連イベントの紹介：イベント名、開催日時、会場、開催形式を掲載する
- 休憩案内：休憩中であることと再開時刻を案内する
- クロージング：参加への感謝を伝え、イベントの終了を案内する
- アンケートの案内：アンケートへの回答を依頼する
- 次回イベント・コミュニティの案内：次回のイベントやコミュニティへの参加を呼びかける
- 残り時間の案内：登壇者向けに残り5分、3分、1分を表示する
