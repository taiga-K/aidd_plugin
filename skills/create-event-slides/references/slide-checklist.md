# スライド完了チェックリスト

## 内容

- [ ] 対象イベントと必要なデフォルトスライドを確定した
- [ ] 日時、曜日、会場、登壇者名、セッション名、ハッシュタグを一次情報と照合した
- [ ] アジェンダの進行順とスライドの順序が一致している
- [ ] 未確定情報とプレースホルダーが残っていない
- [ ] 同じ内容を繰り返し掲載していない

## デザイン

- [ ] すべてのスライドが16:9で統一されている
- [ ] 承認済みテンプレートの配色、書体、余白、ロゴ配置を維持している
- [ ] 1枚につき1つの役割またはメッセージに絞っている
- [ ] タイトルを1行に収め、長い場合も意味の切れ目で2行に分けている
- [ ] タイトル直下に不要なサブタイトルや導入文がない
- [ ] 文字切れ、要素の重なり、不自然な折り返し、余白不足、画像の欠落がない
- [ ] スポンサーのロゴは色と縦横比を変更していない

## 出力

- [ ] すべてのスライドを画像またはPDFで書き出し、目視で確認した
- [ ] URLとQRコードのリンク先が正しい
- [ ] 会場で投影したときに読める文字サイズとコントラストになっている
- [ ] 作成者とは別の人またはエージェントが全スライドを読み、分かりにくい日本語や進行上の不足がないか確認した
