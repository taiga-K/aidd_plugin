### connpass情報の取得

**公式APIから必要な情報だけを取得する。**

1. **connpass-api** の `SKILL.md` と参照ファイルを全文読む。
2. ユーザーの要望とURLから、取得対象、ID、サブドメイン、ニックネーム、検索条件を特定する。
3. `CONNPASS_API_KEY` の設定有無を値を表示せずに確認する。未設定の場合は結果を `未実行` とし、手順4と5を `skip: CONNPASS_API_KEYが未設定` にして **aidd-setup** を案内する。
4. 必要最小限の条件でconnpass API v2へGETリクエストを送る。全件取得を求められた場合だけページネーションする。
5. 取得対象、件数、主要な結果、connpass上のURLを整理する。APIが返さない値を推測で補わない。

Webページのスクレイピング、API v1、connpassへの書き込み操作は使用しない。

**完了報告：** APIから結果を取得できた場合は、使用した検索条件、取得件数、ユーザーが求めた情報、参照先URLを返す。APIを実行しなかった場合は `未実行`、APIが失敗した場合は `取得失敗` とし、原因と次に必要な操作を返す。どちらも取得件数を0件として扱わない。APIキーは表示しない。
