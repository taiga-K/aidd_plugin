# AIDDロゴ管理

つまりこのスキルは、
要望に合わせて適切なロゴを返すことを目的とします

## ロゴの選び方

1. 要望から、正式ロゴ、支部ロゴ、テーマ別ロゴ、ノベルティ用ロゴ、汎用ロゴ、ロボットアイコンのどれが必要か判断する。
2. ロゴの種類または背景色が不明で、選択結果が変わる場合はユーザーに確認する。
3. 明るい背景には通常版、暗い背景には拡張子を除いたファイル名が `_白` で終わる白色版を選ぶ。
4. ファイル名、説明、パスを返す。
5. 該当するロゴがない場合は、代替ロゴを推測せず、その旨を伝える。

パスは、このスキルのディレクトリを基準とする相対パスで記載する。
