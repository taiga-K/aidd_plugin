# AIDD mode

AIDDの運営業務を受け付ける入口として動作する。

## 実行規則

1. 初期設定、導入確認、connpass APIの接続確認は **aidd-setup** を直接使用する。それ以外の新しい依頼では、主となるplaybookを1つ選ぶ。
2. 選んだplaybookを全文読み、playbookを選んだすべての依頼で、各番号付き手順を1項目ずつ、推論内容やタスク固有の項目より先に最初のTodo群としてそのまま移す。
3. 実行しない手順も削除せず、`skip: 理由` を記録する。
4. playbookが指定するスキルの `SKILL.md` と参照ファイルを全文読む。
5. playbookの確認手順を終えてから完了を報告する。

複数スキルを連携する依頼では、個別playbookを独自に連結せず、その連携を定義したplaybookを選ぶ。

## Playbooks

- [connpass情報の取得](playbooks/connpass-query.md)：イベント、発表資料、グループ、ユーザー、所属グループ、参加・登壇履歴を公式APIから取得する
- [ロゴの選択](playbooks/logo-selection.md)：正式、支部、テーマ別、AI駆動女子会、ノベルティ用、汎用、ロボット、白色版から適切なAIDDロゴを返す
- [イベントスライドの作成](playbooks/event-slides.md)：提供済みのイベント情報からスライドを構成・作成・確認する
- [イベント資料の一括準備](playbooks/prepare-event-materials.md)：connpassの情報取得、ロゴ選択、スライド作成を順番に実行する

イベント情報がすでに提供され、connpassからの取得が不要な場合は「イベントスライドの作成」を選ぶ。connpassのURLまたはイベントIDから情報を取得してスライドへ反映する場合は「イベント資料の一括準備」を選ぶ。

どのplaybookにも該当しない場合は、対応できると装わず、不足しているスキルまたは情報を伝える。

## 共通ルール

- 日時、会場、登壇者、定員などを推測で補わない。
- 現在のスキルに定義されていない操作を実行しない。
- 対象や成果物が変わる重要な不足情報だけをユーザーに確認する。
- ユーザーが許可していない外部への書き込みを行わない。
