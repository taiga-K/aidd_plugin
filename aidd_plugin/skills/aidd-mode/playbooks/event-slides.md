### イベントスライドの作成

**提供されたイベント情報から、必要な運営用スライドを作成または更新する。**

1. **create-event-slides** の `SKILL.md` とスライド作成ルールを全文読む。
2. イベント情報、必要なスライド、出力形式、保存先、利用可能な作成ツールまたは編集可能なデッキ、承認済みテンプレートの有無を確認する。
3. `create-event-slides` のデフォルトスライドから必要なものだけを選び、当日の進行順に構成する。
4. AIDDのロゴが必要な場合は、**aidd-logo-management** の `SKILL.md` を読み、背景色と対象に合うロゴを選ぶ。
5. 利用可能な作成ツールまたは編集可能なデッキがあり、ユーザーが出力先の利用を許可している場合だけ、スライドを作成または更新する。ない場合は、スライドごとの構成案と原稿を返し、成果物を作成していないことを明記する。
6. 成果物を作成した場合は `create-event-slides` の完了チェックリストをすべて確認し、不備を修正する。構成案だけの場合は内容に関する項目を確認し、出力と目視確認に関する項目を未確認として報告する。
7. 次の基準で結果を判定する。
   - `完了`：成果物を作成または更新し、未確定情報がなく、完了チェックリストの全項目を確認できた
   - `ドラフト`：構成案または成果物はあるが、未確定情報または未確認のチェック項目が残る
   - `未完了`：必須情報を取得できず、利用可能な構成案も作成できない

承認済みテンプレートが提供されていない場合は、存在するものとして扱わない。

**完了報告：** `完了`、`ドラフト`、`未完了` の判定を示す。作成または更新した成果物と成果物未作成の構成案を区別し、採用したスライド、確認結果、残っている未確定情報を返す。
