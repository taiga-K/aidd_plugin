# スライド作成ルール

このファイルをイベントスライドの作成基準とする。ユーザーの明示的な指示を最優先し、承認済みのイベントテンプレートがある場合はその仕様に従う。

## 作成前に内容を決める

- 対象イベント、聴衆、投影する場面、必要なスライドを先に確認する。
- イベントページなどの一次情報から、日時、会場、登壇者、セッション名、ハッシュタグを確認する。
- 不明な情報を推測で補わない。
- 各スライドで伝える内容を1行ずつ並べ、当日の進行に沿って読める構成を先に作る。
- 必要なスライドだけを選び、情報を増やすためだけにスライドを追加しない。

## スライドサイズとデザイン

- スライドの比率は16:9にする。
- 承認済みテンプレートがある場合は、配色、書体、余白、ロゴ配置を変えない。
- 書体は見出し用と本文用の2種類までにする。
- スライド全体でヘッダー、余白、書体、色の使い方を統一する。
- ブランド指定がない場合は、色数を抑えた中立的な配色を使う。

## 1枚に1つの役割を持たせる

- 1枚につき1つの案内または1つのメッセージを掲載する。
- 関係のない内容を上下に積まない。
- タイムテーブルや関連イベントの情報が収まらない場合は、文字を縮小せず複数枚に分ける。
- 装飾のためだけのカード、ラベル、矢印、帯を置かない。
- 下部に結論や要点を繰り返すメッセージ帯を置かない。
- 角丸のボックスを使わない。時刻や状態を示す小さなラベルだけを例外とする。



## タイトルと文章

- タイトルだけで、そのスライドの役割や伝える内容が分かる文言にする。
- タイトルは1行を基本とし、長い場合は意味の切れ目で2行にする。
- タイトルを収めるために本文より小さくしない。
- タイトル直下に、タイトルを言い換えるだけのサブタイトルや導入文を置かない。
- 開始前案内、休憩案内、クロージングなどの運営用スライドには、用途が分かる定型表現を使う。
- 参加者向けの案内文は自然な敬体で書き、ラベルや見出しは簡潔にする。
- 同じ内容を指す用語や表記は、スライド全体で統一する。
- 略語は初出で正式名称を併記する。
- 長い段落を置かず、列挙する情報は短い箇条書きに分ける。
- プレースホルダーや未確定情報を残す場合は、その旨を明記する。



## レイアウト

- 情報は上から下、左から右へ自然に読める順序で配置する。
- 図や写真と説明を並べる場合は、図や写真を左、説明を右に置く。
- 比較する情報は、独立したボックスの羅列ではなく共通の軸を持つ表で示す。
- 塗りのあるボックスに枠線を付けない。
- 罫線は情報を区切る場所だけに使う。
- 並列する要素の高さ、間隔、文章の粒度を揃える。
- 画像の縦横比を維持し、引き伸ばさない。



## アジェンダと表

- アジェンダは、「時間」「セッション名」「登壇者」の列で整理する。
- 表の見出しは本文より大きく、太字にする。
- 表の見出しは背景色ではなく太い下罫線で区別する。
- 行間には細い罫線を使い、最終行の下には罫線を引かない。
- 長いセッション名や登壇者情報で読みにくくなる場合は、行数を減らして複数枚に分ける。
- セッションの進行中にアジェンダを再掲する場合は、現在位置が分かるようにする。



## 色と素材

- 新たに作成する文字、図形、背景にはイベントのブランドパレットを使う。指定がない場合は中立的な配色を使う。第三者から提供された素材には、この色の制限を適用しない。
- 色に意味を持たせる場合は、スライド全体で同じ色を同じ意味に使う。
- スポンサーから提供されたロゴデータを使い、色や縦横比を変更しない。
- 出典不明の画像や、利用条件を確認できない画像を使わない。
- 会場で投影したときに読めるコントラストを確保する。
